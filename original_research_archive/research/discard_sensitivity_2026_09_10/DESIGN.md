# Report design and reading order

The opening visual is a flow diagram showing retained landings, designated
discards and their alternate destinations. It introduces the actual experimental
choice before any headline result. A compact explanatory paragraph states that
the existing source-model catch is split, and that the fixed-catch comparison
does not fit a new ecosystem for each year.

Use a white page, deep Atlantic blue `#173F5F` for structure, marine teal `#007F83`
for catch routing, ochre `#9A6400` for the M0 proxy, violet `#7855A3` for external
loss, and muted slate `#536779` for context. Text uses the local Segoe UI/Tahoma
stack; numerical columns use tabular figures. Georgia is reserved for the short
report title. All assets are embedded and fonts need no download.

The control strip sits above a wide sensitivity chart and a numerical result
table. A vertical marker identifies the chosen fraction. Invalid points create
gaps; no line is drawn across them. The next panel separates coefficient, catch
boundary and interaction effects. A group contribution table and sortable
cross-model summary follow. Source evidence, model domain, numerical diagnostics
and the reporting protocol remain inspectable below the scientific results.

Control labels use full user-facing meanings: model; calculation method; basal
source scope; discard route; percentage of existing modeled catch designated as
discards; evaluated catch; result measure. A second return-percentage control will
appear only if that additional experiment is actually run. Hypothetical fractions
must never be presented as observed source-model discard rates.

Use shared scales for compared routes, explicit native units, signed excess or
deficit labels and scenario-specific validity. The envelope caption names the
contributing routes and omitted invalid cases. The default view is Bay of Bengal
where valid. Failed defaults must display their explanation, not silently choose
another model or method. CSV/JSON downloads and print styles use the same embedded
verified records as the interactive chart.
