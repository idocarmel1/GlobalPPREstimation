
Command line options:

 -M[x] 
 Run mode x (x is 1 or 2 letter code).  Possible modes:
   [o] One run:  Do one run (mainly for testing)
   [f] Fitting:  Find max liklihood fit to data
   [e] Sense Generate:  Generate a number of random ecosystems and 
	     filter by non-death criterion.  Save surviving ecosystems in 
			 binary format files.
   [i] Sense Report:  Take surviving ecosystems from previously
	     generated sense set and report statistics (e.g. for making 
			 quartiles) 
   
 -O[path]/[file]  
   Set output path and filename base
 
 -I[path]/[file]
   For runmodes that take input files, input file path and filename base
 
 -S[n] 
   Number [n] of random ecosystems to generate per thread
 
 -B[n]  
   Years to run [n] in checking for system collapse for the sense 
	 generate [e] mode
 
 -R[n] 
   Set random seed for code.  Unique values are 0 to 511 (anything 
	 outside this range is taken modulus 512)
 
 -A[f]
   Multiply biomass by area multiplier f to scale output files (e.g. 
	 convert to tons or carbon).  Doesn't affect calculations, only
	 output units.

 -V Adjust functional response defaults with suboptions as follows:
 
 -Vv[f] Set range of variance for vulnerability parameters to [f], on
        log scale (default is f=6.0, max for practical purposes 6.0).
 
 -Vx[f] Set default vulnerability for all groups (in absense of input
        parameter file).  Default=2.0 (also EwE default)

 -Vd[f] Set default handling time for all groups (in absense of input
        parameter file).  Default=1000.0 (also EwE default)

 -Vh[f] Is satiation (handling time) independent  (f=1.0) or pooled
        (f=0.0).  Default is 1.0, which is OPPOSITE of EwE default of 
				0.0.
				
 -Vs[f] Is predator density dependence (vulnerability) independent 
	      (f=1.0) or pooled (f=0.0) or in-between? Default is 1.0, 
				also EwE default.

 -C[file]
   Read in climate from .csv formatted [Climate file]
 
 -J[file]
   Read in juvenile parameters from .csv formatted [Juvenile file]
 
 -F[file]
   Read in timeseries fitting data from .csv formatted [Fitting file]
 
 -P[file]
   Read in functional response values (e.g. vulnerabilities) from .csv 
	 formatted vector [Vector fitting file]
 
 -K[file]
   Read in fitting control .csv file (e.g. turn fitting on and off 
	 specific parameters for phased fitting) [Vector control file]
