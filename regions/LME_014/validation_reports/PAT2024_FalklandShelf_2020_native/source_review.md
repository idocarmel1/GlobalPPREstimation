# Falkland shelf 2020 source and regional review

The regional review covers all 250 exact catch labels and 37 computational groups. Review completion does not approve whole-LME applicability: all three methods remain WARN, the source is a subregional 2020 shelf model, and 196 Very low labels represent 32.676936% of 2019 landings and 6.237314% of independent classic PPR.

## Source layers and scientific limitations

Büring et al. (2024), JMBA 104 e2, DOI 10.1017/S0025315423000887, is retained under historical PAT-2023. The verified main PDF, S1/S2 CSV, native S0025315423000887sup002.eweaccdb, and S3 DOCX are all present; source material availability does not constitute loadability or scientific approval. The native file contains one 2020 Ecopath model, 36 groups, 1,296 explicit diet rows and 72 complete fleet/group catches. EcopathGroup Sequence, rather than GroupID, is the canonical identity crosswalk. Table 4 uses separate Discards and Detritus; Table 2/S2 use a combined detritus description. S3 initial 45 groups are not a second accepted final parameterization. Native and printed/S2 diet differences exceed ordinary presentation rounding in some cells; [retained comparison](../../models/extraction_review_20260928/evidence/native_vs_published_differences.json) identifies them.

The [independent source comparison](source_fidelity_verification.json) checked 1,592 scalar/diet cells. Ten native binary-float to canonical decimal tails are below 1e-14. Eight canonical −9999 diet sentinels for nonconsumer Kelp/Phytoplankton/Discards/Detritus consuming detritus are preserved; native cells are zero. These are nonoperative row conventions, not source values restored in this review. Complete native landings and discards, including true zeros, reproduce accepted group catch. Native GS, explicit zero BA, Kingclip immigration, fate and fleet-discard routing remain unchanged.

Thirteen source-missing B values are completed jointly with missing EE in the accepted computational input. An independent rank-13 solve reproduces every accepted living B/EE; residual 1.13e-14. Canonical source unknowns remain unknown. The native living fate and both fleets' discards route to Detritus 36, while five consumers eat Discards 35. The accepted loader compensates that unsupplied pool with negative detritus BA; no rebalance or invented routing was applied. The earlier default-loader FAIL and audited completion WARN are separate variants. Converter output, canonical reconstruction, all eight source tables, roundtrip and cell provenance remain retained under [extracted tables](../../models/PAT2024_FalklandShelf_2020_native/extracted_tables/REPORT.md).

## Membership and reporting scope

[All 250 keyed decisions](taxon_audit.json) give positive taxonomy/habitat connections, competing pools, genuine mismatches and include/exclude decisions across all 37 groups. Named Table 2 taxa retain direct membership; bivalves belong to the explicit Small Zoobenthos definition. Family/genus labels receive supported extensions rather than invented unique species. Juvenile toothfish is a same-species Very low analogue for unsplit adult/deep catch; the source explicitly excludes adults/longliners. Shrimp/crab labels have a positive benthic decapod connection to adult Munida; taxonomy, body size and geography differ. Croakers and other unlisted demersal fishes connect to the two residual bottom-fish pools. Source Small/Large names have no numeric length threshold, so provider size bins cannot select only one.

Broad fish, cephalopod, mollusc and crustacean labels include relevant named source pools as well as residual pools. Pelagic fish includes Blue Whiting/Hoki, Myctophidae, mixed Pelagic Fish and pelagic Lamna. Adult benthic and juvenile planktonic Munida remain separate candidates for broad crustaceans. Marine finfishes uses the provisional FAO Osteichthyes reporting interpretation; exact SAU code crosswalk is unverified and confidence remains Very low. Rajidae common name Stingrays conflicts with current family scope; use an explicit weak ray analogue. Diet differences describe scientific limits but are not a new mapping eligibility requirement.

The six largest Very low classic-PPR exposures are: Pomatomus saltatrix (1.4754%), Marine fishes not identified (1.0692%), Cynoscion guatucupa (0.7067%), Micropogonias furnieri (0.6159%), Pleoticus muelleri (0.3457%), Pagrus pagrus (0.2959%). Unresolved labels: none. Provisional coverage never means ecological identity.
