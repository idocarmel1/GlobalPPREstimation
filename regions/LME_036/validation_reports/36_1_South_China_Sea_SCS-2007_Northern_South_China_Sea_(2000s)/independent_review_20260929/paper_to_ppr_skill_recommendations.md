# Paper-to-PPR skill recommendations from the LME036 test

29 September 2026. Recommendations only; no skill, code, model, workbook or map changes and no scientific stage executed. The active entry point is [paper-to-PPR SKILL.md](<../../../../../tools/skills/original_skill_resources/combined-src/SKILL.md>), under `combined-src`, not the archived Claude/Codex copies.

The current references already require full diagnostic returns, source/runtime separation, transformation ledgers and evidence-backed mappings. The main improvement is to make these requirements a checked, portable handoff contract rather than prose that can coexist with incomplete historical exports. These recommendations are based on [the independent review](review_evidence.md), [its mismatch ledger](alignment_mismatches.csv) and [verification record](draft_verification.json), not a fresh code audit.

## Priority 1 — retain enough scientific evidence to validate without rerunning

**1. Make each diagnostic run self-contained.** Change [direct-diagnostics.md](<../../../../../tools/skills/original_skill_resources/combined-src/references/direct-diagnostics.md>) and its handoff in [regional-calculation.md](<../../../../../tools/skills/original_skill_resources/combined-src/references/regional-calculation.md>). For each explicitly requested method, retain the losslessly serialized full diagnostic return and returned coefficients from the same execution; a labeled group × basal-source contribution matrix whenever that formulation supplies one; exact ordered row/column IDs and names; units, orientation and source-scope definitions; synthetic-group flags; and explicit null/nonfinite masks. Store all retained groups, including unfished groups. Scalar formulations must state that a decomposition is unavailable rather than invent one.

Also retain method/option, settings, input/runtime/code hashes, constructor identity, thresholds/tolerances, timestamp, exception/timeout details, overall/component grades and strict flags. Include rho_living, named detritus-pool SPPR, and the definition/applicability of recycling b. A recorded TE convention b=0 must not imply absent physical recycling. A convenience negative-entry table should identify source and recipient group IDs, values and the comparison tolerance, but never replace the underlying matrix. The handoff check should reopen the files, verify axes and reconcile sums with saved coefficients/diagnostic summaries; an aggregate-only export is explicitly incomplete.

*LME036 reason:* `sppr_source.xlsx` retains scope aggregates and zero-negative-source counts but expressly omits source breakdowns. Validation could reproduce neither the all-entry sign check nor exact negative source/group pairings. Retaining matrices during the original authorized run would remove this reason for another scientific run.

**2. Retain the exact transformation chain and balanced state.** Change [reconstruction-audit.md](<../../../../../tools/skills/original_skill_resources/combined-src/references/reconstruction-audit.md>), [direct-diagnostics.md](<../../../../../tools/skills/original_skill_resources/combined-src/references/direct-diagnostics.md>) and [regional-calculation.md](<../../../../../tools/skills/original_skill_resources/combined-src/references/regional-calculation.md>). Save separate, identified snapshots for source-faithful canonical input, explicit computational input, pre-initialization state, loaded state and **`PPRCalculator.balanced_model`**. Record a semantic fingerprint covering ordered groups, parameters, diets, routing, catches/flows, unknown markers and units, as well as file hashes. Capture the executed constructor/call settings and versioned code/environment needed to interpret the state, plus a field-by-field ledger: group/field, old and new value, missing/sentinel meaning, transformation category, equation/operands or normalization factor, source locator, reason and authorization reference. Include synthetic groups, solved BA, imposed GS, diet normalization and every included/excluded group.

The user's requirement for the later update is that **map-bound calculations and linked/filtering model data use `PPRCalculator.balanced_model`**. Retain an explicit provenance link from that balanced-state fingerprint to group coefficients, selected-model data, filtering/group lists and regional results. Derived views must record their projection/filter; they need not be byte-identical. Integration must retain proof that displayed model details and calculated values come from the same balanced state. Keep source-faithful input separately available for comparison. This is a required future contract, not a claim that current code meets it; no code was independently re-audited here.

*LME036 reason:* 81 inspected canonical/saved-field differences, 38 source versus 39 runtime groups, missing GS/BA and normalized runtime diets could be observed, but the complete historical transition could not be reconstructed. The researcher's SPPR exclusion note also did not match the retained full group set. Store researcher intent separately from executed exclusions; never infer implementation from a manual note.

**3. Add a portable evidence inventory, not another source of project status.** Change the entry point, [model-preparation.md](<../../../../../tools/skills/original_skill_resources/combined-src/references/model-preparation.md>) and the diagnostics handoff. Require a versioned evidence folder/index with `schema_version`, region/model/variant IDs, source and computational/balanced identities, run ID, artifact paths and hashes, methods and artifact availability. Link source files, tables, taxonomy, transformation ledger, full returns, matrices and coefficient tables. Missing items need explicit reasons and acquisition status. Use portable links into retained regional/research evidence, not temporary or ignored runtime paths. Selection/configuration authority remains Overview/Project.xlsx; the inventory is evidence only. Validate files against a small required-field/completeness checklist, including failed and partial runs, before declaring the scientific handoff complete. Validation can then find and authenticate existing evidence without searching historical exports or executing a constructor.

## Priority 2 — make mapping judgments reproducible and consistent with adoption

**4. Store separate membership, allocation and assumption evidence.** Change [group-taxonomy.md](<../../../../../tools/skills/original_skill_resources/combined-src/references/group-taxonomy.md>), [size-stage-allocations.md](<../../../../../tools/skills/original_skill_resources/combined-src/references/size-stage-allocations.md>) and [regional-calculation.md](<../../../../../tools/skills/original_skill_resources/combined-src/references/regional-calculation.md>); cross-reference the rule definitions in the [validation template guide](<../../../../../tools/templates/Model_validation_template_instructions.md>) rather than duplicate them. Preserve the three-column `Taxonomy.xlsx` contract; put richer evidence in a companion table. Retain exact taxon and group IDs, source spelling and accepted synonym/authority ID, exhaustive versus representative membership, residual-category meaning, habitat/size/stage bounds and measurement unit, source table/page/cell, period/area/basis, each candidate including zero weights, and conflicts.

For every mapping retain membership rule/confidence/evidence and weight rule/confidence/evidence separately, overall review category and rationale, adopted decision/version and prior decision. Keep an independent `assumed` flag and assumption type so the High/Medium/Low/Unresolved display cannot erase assumption-dependent coverage. Retain observed mass numerators/denominators and conversions where available, or exact source/raw/effective/loaded catch values and proxy formula. A search record needs query/date/URL, what was actually read, source version or retained excerpt, applicability and rejection/adoption reason; distinguish full text from a snippet or blocked page.

*LME036 reason:* the 135 retained stage-proxy ledgers made arithmetic verification possible, but `assumed` did not directly map to report confidence, and confidence was sometimes driven by uncertain membership rather than weights. Thirty mappings lacked supported complete composition; Mollusca and Dendrobranchiata illustrated why a broad label cannot automatically mean a residual model pool. Authoritative evidence remains needed even if identifiers and weights are numerically valid.

**5. Add a review-to-adoption completion checkpoint.** Change [regional-calculation.md](<../../../../../tools/skills/original_skill_resources/combined-src/references/regional-calculation.md>), [project-integration.md](<../../../../../tools/skills/original_skill_resources/combined-src/references/project-integration.md>) and the entry-point handoff; coordinate the later update with [validation SKILL.md](<../../../../../tools/skills/ecopath-model-validation/SKILL.md>). A draft may show proposed changes, but **a final validation report must agree with the adopted regional data and map**. Report-only reclassification is not an acceptable final state. Use a keyed discrepancy ledger recording old/proposed group/weight/confidence, rule/evidence, decision, affected catch/PPR basis and adoption state. Separate metadata-only confidence corrections from removal or alteration of numerical weights. Do not treat classic-PPR exposure as the expected change in GE/TE PPR.

After authorized adoption, reconcile canonical Matching and Allocation assumptions, then recalculate only dependent regional outputs where needed, retaining original group SPPR if its input/state/configuration is unchanged. Propagate affected regional records to Project.xlsx and rebuild/verify map, trends and archive. Record the same adoption/run identity across retained evidence and outputs; compare IDs, selected/balanced state, mappings, confidence/assumption labels, method restrictions, year/basis/scope/treatment, coverage, totals and carbon conversion. Include generated payload and visible browser checks, including remembered selection. Derive final Word summary/appendix from those adopted rows. If adoption is deferred, keep the report explicitly a pending-alignment draft.

*LME036 reason:* 168 review/adopted differences comprise 138 confidence-only differences and 30 proposed unresolved numerical mappings. The exact proposals and minimum propagation scope are in [future_alignment_proposal.md](future_alignment_proposal.md). They remain unadopted; this recommendation does not authorize them.

## Priority 3 — preserve contextual evidence and denominator contracts

**6. Save source identities, scope and arithmetic context once.** Change [model-preparation.md](<../../../../../tools/skills/original_skill_resources/combined-src/references/model-preparation.md>), [missing-data-recovery.md](<../../../../../tools/skills/original_skill_resources/combined-src/references/missing-data-recovery.md>) and [regional-calculation.md](<../../../../../tools/skills/original_skill_resources/combined-src/references/regional-calculation.md>). Retain citation/DOI/accession, exact source version and hash, printed and PDF page locators, competing table versions and selection rationale. Store publication date, model period and catch year separately. For geography retain the selected-model figure/caption, region-boundary identity, model-period applicability and available area/polygon/trace evidence; any visual overlap estimate needs method, landmarks, A/B denominators and uncertainty. Do not infer measured coverage from a picture or filename.

For report arithmetic retain the exact catch universe including zero rows, available source bases versus assessed basis, taxon join keys, TL/coefficient source and snapshot, coefficient method/TE, native and displayed units, the single wet-weight-to-carbon conversion, missing masks, unresolved inclusion rule and unrounded totals. Store source-to-result reconciliation for the chosen year/basis. These are frozen evidential extracts of authoritative workbook tables, not replacement configuration. LME036 had 374 landings labels, 53 zero-landings labels and 34 unknown classic coefficients with zero landings; unknown PPR must remain unknown. Its source offers three catch bases, while the assessment uses 2019 landings throughout.

## Execution permission and limits

Add the user's **explain-and-confirm requirement** to the entry point and each executable-stage reference. Before every proposed fresh scientific run, state the gap, why saved evidence cannot answer it, smallest sufficient stages, exact inputs/state/settings, expected artifacts, estimated bounds and potential file/result changes; obtain explicit confirmation before execution. Confirmation of one concrete run covers that scope, not an expansion, numerical repair or adoption. Reusing saved evidence and report arithmetic does not require a scientific rerun. Finish independent review first. No broad exporter, extraction, balancing, SPPR regeneration or downstream recalculation may be silently used to fill missing documentation.

Missing records and scientific uncertainty require different remedies:

- **Missing retained information:** complete diagnostic matrices, exact state/constructor provenance and transformation evidence. Better retention prevents repeat runs; it cannot retroactively recreate LME036's omitted matrices. The narrowly scoped GE/TE recommendation remains pending in the evidence review.
- **Inconsistent adopted data:** review classifications versus canonical mapping/map state. Resolve through explicit adoption or retain a draft; logging alone does not align results.
- **Genuine uncertainty:** missing source GS/BA/native conventions, conflicting stage boundaries, unobserved species-specific caught-mass composition, geographic/temporal proxy transfer and approximate overlap. Preserve limitations and request specific new evidence or an explicitly authorized assumption. More diagnostics, detailed logs or a clean report cannot prove these assumptions scientifically correct.

No files listed above were edited. The next skill-updating task should turn these evidence fields and completion checks into the current references, preserve the user's researcher-document protections, and test the handoff using saved evidence before proposing any new scientific execution.
