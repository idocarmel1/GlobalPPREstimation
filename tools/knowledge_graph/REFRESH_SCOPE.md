Structural extraction parses code without executing any project algorithm. Changed documents are read by host semantic-extraction agents using the graphify confidence rubric. The installed graphify version prunes after merging when `build_merge(prune_sources=...)` is used, which would also discard newly extracted nodes from changed files. The refresh helper therefore filters only the old graph first and then uses `build_merge` on that retained graph. This is a graph-maintenance workaround; no PPR algorithm or Jensen calculation is changed.
