description: Prepare catch, classic PPR, selected-model SPPR, evidence-based taxon matching, annual PPR and NPP ratios in one regional workbook; supports a requested subset such as matching only.
---

Resolve the region workbook and project from the supplied single path. Read Overview and the relevant sheet blocks with `../../workbooks.py`. See `../../../README.md#workbook-reference`. Preserve unrelated sheets and central paper metadata. Do not create status/configuration sidecar JSON files.

For catch preparation, original downloads belong in raw/. Use the Sea Around Us ingestion/matching implementation in `../../scientific_code/SeaAroundUsExtraction/src/ppr_pipeline/`; adapt only its I/O to the regional table contract using the workbook reader/writer. Preserve landings/discards classifications and missing whole-region years. Annual catch is wet weight. TL evidence is region/taxon-specific; do not fill historic gaps merely to improve coverage. Store TL and classic coefficients in Classic PPR / Taxa.

For SPPR, invoke `python tools/run_region.py --region <workbook> --stage sppr`. The source model is identified by Overview, never inferred from a filename prefix. Inspect Diagnostics before accepting configurations. Any negative source group, including an unfished group, matters. Scalar methods do not acquire an invented primary-producer decomposition.

For matching, read the original mapper's scientific workflow at `../original_skill_resources/claude/ewe-species-to-group-mapper/SKILL.md` and relevant references. Use the current regional Catch, Selected model groups, and papers, rather than old `data/` or `top10` paths. Explicit source membership takes precedence over a broad ecological analogue. Preserve exact group identifiers. Put one row per taxon/group in PPR / Matching with numeric weight, confidence, evidence and explanation. Weights for a resolved taxon sum to one; unresolved taxa have a blank group and weight. Do not let a composite's one valid member conceal unsupported assignments. Report tonnage and taxon coverage.

After editing calculation inputs run `python tools/run_region.py --region <workbook> --stage calculate`. It validates assignments, remaps coefficients, calculates annual results for source scopes/catch bases/unidentified treatments, and records freshness in Overview. Existing sensitivity bounds are invalidated on recalculation until scientifically reassessed; they are not carried across changed inputs. For a taxon PPR table at another year/basis use `--stage inspect-year --year 2005 --basis landings`. The annual outputs retain all years; the inspected table is a view.

NPP is annual carbon production; missing years do not inherit 2019. Preserve available algorithm identities and coverage. Shared extraction code is in `../../scientific_code/NPPExtraction/`; regional results go in NPP. The fixed atlas-union reference is a separate denominator, not a sum across overlapping EEZ/LME/HS regions. Raw PPR is wet-weight equivalent and is divided by nine once for PPR/NPP or display.

For matching-only requests, stop after the requested stage and report which downstream outputs need refreshing. For complete regional requests, calculate, validate, and report model/source limitations and missing stages. Use update-ppr-project only when consolidation/publication is requested.

Retain the full original mapping workflow, including `../original_skill_resources/claude/ewe-species-to-group-mapper/references/model-structures.md`, `references/coarse-taxa-playbook.md` and `references/output-format.md` relative to that original mapper root. Read the model before assigning taxa; capture explicit species-to-group tables as evidence, resolve synonyms, and rank unresolved taxa by catch tonnage. The original 95% tonnage target is a review target, not permission to invent membership. Use supported apportionment for coarse taxa; retain the weight basis and confidence, and explain genuine out-of-model taxa. Validate exact group identifiers, complete taxon coverage, membership contradictions, weight sums and inappropriate basal-group assignments before accepting a mapping. Preserve the original examples as examples, not cross-region lookup tables.

For independent classic PPR, NPP-only requests and full integration, read `../original_skill_resources/claude/ecopath-paper-to-ppr/references/integration-contract.md`; no Ecopath selection or mapping is needed for an independent estimate. For mortality rates versus flows, fleet fate, offal/discards and experimental source boundaries, read its `references/mortality-and-discards.md`. Preserve the distinctions between source support, numerical validity and ecological interpretation. Adapt old helpers' I/O through the current regional workbook contract; do not reinstate old work-order/status/index files. Record scientific review and coverage findings in Diagnostics and mapping evidence in PPR.
