name: calculate-regional-ppr
description: Use when diagnosing SPPR, matching regional catch taxa, calculating regional PPR or NPP ratios, or investigating differences between model years and methods.
---

Resolve the region workbook and project from the supplied single path. Read Overview and the relevant sheet blocks with `../../workbooks.py`. See `../../../README.md#workbook-reference`. Preserve unrelated sheets and central paper metadata. Do not create status/configuration sidecar JSON files.

For catch preparation, original downloads belong in raw/. Use the Sea Around Us ingestion/matching implementation in `../../scientific_code/SeaAroundUsExtraction/src/ppr_pipeline/`; adapt only its I/O to the regional table contract using the workbook reader/writer. Preserve landings/discards classifications and missing whole-region years. Annual catch is wet weight. TL evidence is region/taxon-specific; do not fill historic gaps merely to improve coverage. Store TL and classic coefficients in Classic PPR / Taxa.

For SPPR, read [direct-diagnostics.md](references/direct-diagnostics.md). Default to full direct GE, TE and With Egestion returns, excluding global and Monte Carlo. Preserve NOT_RUN, exceptions, unsupported equations, FAIL and WARN distinctly. `run_region.py --stage sppr` calls a broader exporter; reserve it for an explicitly requested broader calculation. Identify the exact source/runtime model from Overview or the named candidate, never a filename prefix. Audit missing biology and loaded mutations before interpreting results. Negative source groups, including unfished groups, matter. Scalar methods do not acquire an invented primary-producer decomposition.

For matching, read the original mapper's scientific workflow at `../original_skill_resources/claude/ewe-species-to-group-mapper/SKILL.md` and relevant references. Use the current regional Catch, Selected model groups, and papers, rather than old `data/` or `top10` paths. Explicit source membership takes precedence over a broad ecological analogue. Preserve exact group identifiers. Put one row per taxon/group in PPR / Matching with numeric weight, confidence, evidence and explanation. Weights for a resolved taxon sum to one; unresolved taxa have a blank group and weight. Do not let a composite's one valid member conceal unsupported assignments. Report tonnage and taxon coverage.

Exact/synonym matching is the first pass. Review high-tonnage unresolved labels for source-supported aliases and containment. If all supported constituents belong to one group, within-pool proportions are unnecessary; if they span groups, require supported membership and allocation weights. Distinguish representative from exhaustive lists, missing model structure from spelling issues, and taxon labels from species. Find missing membership evidence using [online recovery](../prepare-ecopath-model/references/missing-data-recovery.md), not broad guild-name inference.

Report resolved labels and catch-tonnage coverage by year and basis, with the largest unsupported catches. Geographic overlap is separate. Label supported-catch subtotals as partial; fixed-period coefficients over historical catch do not reconstruct annual ecosystems. For PPR differences, separate catch quantity/composition, coefficients, scope, mapping support and feedback. High positive SPPR or a lower PPR alone is not an accuracy criterion; use diagnostic/source evidence rather than invented universal cutoffs.

After editing calculation inputs run `python tools/run_region.py --region <workbook> --stage calculate`. It validates assignments, remaps coefficients, calculates annual results for source scopes/catch bases/unidentified treatments, and records freshness in Overview. Existing sensitivity bounds are invalidated on recalculation until scientifically reassessed; they are not carried across changed inputs. For a taxon PPR table at another year/basis use `--stage inspect-year --year 2005 --basis landings`. The annual outputs retain all years; the inspected table is a view.

NPP is annual carbon production; missing years do not inherit 2019. Preserve available algorithm identities and coverage. Shared extraction code is in `../../scientific_code/NPPExtraction/`; regional results go in NPP. The fixed atlas-union reference is a separate denominator, not a sum across overlapping EEZ/LME/HS regions. Raw PPR is wet-weight equivalent and is divided by nine once for PPR/NPP or display.

Global satellite inputs live once in `../../../common_reference_data/npp/raw/`, not in regional raw folders. Read that directory's parent README and `../../scientific_code/NPPExtraction/ANNUAL.md` before extraction. Use the NPP environment with `python tools/verify_npp_sources.py` to verify original bytes, then `python tools/run_npp.py plan` before an authorized `run`. These root-relative commands use the current layout from any working directory when the script path is absolute. Derived decoded/work caches and new output live under `common_reference_data/npp/`; original satellite files are versioned using Git LFS (`git lfs pull` restores them), while derived caches and runtime outputs are local and ignored by Git. Preserve the original raw inputs and their versioned source manifest before cache cleanup. Region raw catch ZIP/JSON/CSV.GZ files do not contain NPP.

The archived `expand_regional_npp.py`, execution snapshots and published annual CSV remain historical evidence. Do not execute archived path assumptions against the live checkout or overwrite its expanded published series. The current annual entry point includes supported NPP years for all current region identities, including those without catch. Adopting newly extracted values is a separate reviewed workbook update: write NPP / NPP and NPP / Provenance, preserve blanks and ensemble membership, then recalculate affected regional results. Extraction alone does not publish workbook or map changes.

Before adopting a new run, preserve its provenance, configuration, executed-code snapshot and source hashes in a versioned research archive or regional evidence folder, and replace runtime absolute provenance references with portable links to that retained evidence. An ignored output directory is not permanent scientific provenance. Only unadopted outputs and reproducible caches may be cleaned without first retaining the evidence supporting published values. Manifest-listed original files must not be silently overwritten by a newly discovered source release; use a separate versioned source location for such a release.

For matching-only requests, stop after the requested stage and report which downstream outputs need refreshing. For complete regional requests, calculate, validate, and report model/source limitations and missing stages. Use update-ppr-project only when consolidation/publication is requested.

Retain the full original mapping workflow, including `../original_skill_resources/claude/ewe-species-to-group-mapper/references/model-structures.md`, `references/coarse-taxa-playbook.md` and `references/output-format.md` relative to that original mapper root. Read the model before assigning taxa; capture explicit species-to-group tables as evidence, resolve synonyms, and rank unresolved taxa by catch tonnage. The original 95% tonnage target is a review target, not permission to invent membership. Use supported apportionment for coarse taxa; retain the weight basis and confidence, and explain genuine out-of-model taxa. Validate exact group identifiers, complete taxon coverage, membership contradictions, weight sums and inappropriate basal-group assignments before accepting a mapping. Preserve the original examples as examples, not cross-region lookup tables.

For independent classic PPR, NPP-only requests and full integration, read `../original_skill_resources/claude/ecopath-paper-to-ppr/references/integration-contract.md`; no Ecopath selection or mapping is needed for an independent estimate. For mortality rates versus flows, fleet fate, offal/discards and experimental source boundaries, read its `references/mortality-and-discards.md`. Preserve the distinctions between source support, numerical validity and ecological interpretation. Adapt old helpers' I/O through the current regional workbook contract; do not reinstate old work-order/status/index files. Record scientific review and coverage findings in Diagnostics and mapping evidence in PPR.

Current runtime inputs are separate from historical studies: the NPP source catalog is `common_reference_data/npp/source_catalog.json`, and map source/model context is `common_reference_data/atlas_source_context/`. These paths are relative to the project root. The only directory under original_research_archive is research, containing named scientific baselines/studies. Resolve older provenance paths through `common_reference_data/provenance/archive_relocation.csv`; do not recreate legacy or reorganization_history directories or depend on deleted historical HTML pages.
