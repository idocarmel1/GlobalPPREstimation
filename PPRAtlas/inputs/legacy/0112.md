# Ecopath source library — all 84 units

This package contains one directory per PPR-ranked Sea Around Us LME/high-seas unit and one subdirectory per recommended Ecopath source. The companion Excel workbook is the authoritative metadata source for the map and package.

## Current inventory

- 84 ranked target areas
- 71 recommended article/model records across 60 areas
- 24 areas with no suitable region-specific Ecopath model located
- 31 validated files belonging to 26 article/model records
- 45 article/model records flagged `unavailable_from_zotero_and_web`
- 403 candidate public endpoints attempted across the selected records

Every verified file is listed in the workbook `Files` sheet with its source URL, size, and SHA-256 checksum. A record is marked `downloaded_verified` only when at least one downloaded material passed format and open checks. Failed HTML/login/error pages are excluded.

## Quality score

The 100-point score is extraction-focused: model loadability 55, documentation 20, spatial fit 15, and recency/validation 10. A source without a verified downloadable file is capped at 25, so broad geographic coverage cannot compensate for an inaccessible model. A downloaded source whose complete reconstruction is still uncertain is capped at 58.

## Data-source rules

Public-web discovery and Zotero searches were performed in parallel. Zotero access was strictly read-only; no Zotero records, attachments, collections, tags, or metadata were changed. Concrete article and repository links were attempted even when no DOI was available.
