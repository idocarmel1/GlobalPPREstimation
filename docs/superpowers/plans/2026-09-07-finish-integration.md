# Finish integration and expose network scopes

The authorized scope is remaining integration tasks 1–5, followed by the requested
scope, method-ratio and recycling views before broad coverage expansion (task 6).

## Design

- Complete the independent Thailand/Okhotsk/Guinea, Arabian/Humboldt/South China
  Sea and new-paper evidence reviews. Preserve model identity, source uncertainty,
  geographic transfer and numerical failures. Keep the new-paper validation isolated.
- Extend the established workbook pipeline with `sppr_inner` and `sppr_PP` sheets,
  annual PPR for each scope, and the upstream recycling diagnostics. Preserve the
  existing all-scope sheets and Jensen comparisons. Missing scope values stay blank.
- Export verified per-model taxon SPPR and rounded annual catches for the atlas.
  Never average models. Ratios use the intersection of taxa with finite values for
  both methods; show the resulting catch coverage and guard zero denominators.
- Gate coloring explicitly to the ten pilot ecosystems with selected articles.
  Model selection is separate from numerical validity. Invalid PPR stays unavailable;
  finite b/rho diagnostics remain visible with their diagnostic status and configuration.
- Add scope, method, ratio, and GE/TE recycling controls to the existing atlas.
  Keep unselected ecosystems available for browsing with neutral styling.
- Rebuild stale Sea Around Us workbook exports with the available bundled runtime,
  without changing catch, trophic-level arithmetic or either Jensen calculation.
