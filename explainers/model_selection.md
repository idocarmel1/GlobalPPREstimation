# Choosing an existing model

Open `regions/{LME,EEZ,HS}/<unit_id>/<unit_id>.xlsx`. Choose `selected_model_id` and enter `selection_rationale` in Overview. Run the refresh command in [workflow.md](workflow.md). `model_path`, Project.xlsx selected flags, pages and the Windows shortcut are generated.

The outgoing result identity comes from `results_model_id`, even after the choice changes. Its full snapshot may therefore display the incoming choice in Overview while containing outgoing results. The adjacent manifest records that distinction. Snapshots restore only compatible model-dependent tables; they never roll back current Catch, classic PPR, NPP or human settings. Unknown historical execution provenance prevents automatic numerical reuse. Missing prerequisites remain pending with an exact reason.

Register a genuinely new model/publication in Project.xlsx first. Discovery establishes paths and IDs, not citation, area, interpretation or validity. See [structure.md](structure.md).
